WHY THE JUDGE MUST WATCH

Metrics can pass.
The machine can still fail.

In an ANYmal stand-still test, a numeric pose metric reported only 2.1° of tilt—yet the rendered frames clearly showed the robot tipping onto its side.

“A design is only as good as the judge, and the judge has to watch the machine work.”

RUN IT LOCALLY

One app.
One command.

AutoMech runs on your machine. The web interface launches the Python pipeline directly and streams every stage back to the browser.

Node 20+Python 3.10+uvModel gateway
automech — zsh
# Create an isolated environment
$ uv venv --python 3.12 .venv
$ uv pip install --python .venv/bin/python \
    -r maker2/requirements.txt \
    -r evaluator/requirements.txt

# Install and launch the interface
$ npm install
$ PYTHON_BIN="$PWD/.venv/bin/python" npm run dev
