maker2 / current implementation

Hierarchical CAD assembly, with deterministic authority.

A prompt becomes a validated articulated machine through a Boss connection graph, parallel subassembly builds, authoritative libslvs placement, real-solid prechecks, visual judgment, and driven physics. Failures return only to the layer that owns them.

Core invariantThe Boss authors topology and typed seams—not final coordinates. Python owns numeric placement, CAD mutation, validation, acceptance, and rollback. The Analyzer is read-only and may select only a Python-generated allowlisted candidate.

01Entry & run state

CLI dispatch

python -m maker2.run "…" --hierarchy --json [--physics] routes to run_boss().

initialize
Session root

Creates <slug>_boss_<timestamp>/, run.log, iteration state, safety ceilings, and keep-best score state.

Flags and controls
  • --kb enables offline retrieval.
  • --web enables reference tools.
  • --deep-think selects the richer worker/debugger path.
  • --no-manager-ir falls back from connection-graph manager IR.
  • max_total_iters and no-progress ceilings prevent runaway loops.

02Boss plans topology

Boss: product → connection graph

Defines subassemblies, frame contracts, typed weld/power seams, and ownership. Replans with prior plan + fault feedback.

deterministic gate
Schema + support gate

Rejects malformed plans and floating power-only structures before any CAD is built.

subassembly_plan.json

Stable sub IDs allow unchanged subassemblies to be reused across Boss iterations.

Boss return: interface/seam/topology fault → replan; rebuild only named affected subs when possible.
What the Boss does not own
  • No authoritative cross-sub placement coordinates.
  • No arbitrary source edits.
  • Rough frame hints may feed the appearance proxy, but libslvs owns solved placement.

03Parallel subassembly build

Manager

Authors parts, mates, ports, and realized frames for one isolated subassembly. Best-of-N or split mode may be used.

mate_solver

Compiles the connection graph into a local KinematicModel; no LLM placement fallback.

Manager gates

Schema, connectivity, frame realization/drift, seat ownership. Declared-box overlap is warning-only.

CAD worker

CadQuery by default; OpenSCAD is the legacy fallback. Emits one script and STL per physical link.

Worker + conflict gates

Watertightness blocks. Real-solid interpenetration invokes a localized subdebugger loop.

Final local validation

Recheck frames after debugging, write URDF, then require MJCF to load in MuJoCo.

Local return: worker defect → worker/debugger; subassembly contract defect → only that Manager reruns. Other built subs remain reusable.
Per-sub outputs
  • sub_<id>/kinematic_model.json and sub_frames.json
  • cq/<link>.py, meshes/<link>.stl, model.urdf
  • SubResult carries the model, build results, realized frames, and status into assembly.

04Authoritative assembly

Namespace + merge

Links become <sub>_<link>; meshes and local poses are consolidated.

Closed-form seed

Provides only an initial guess for the simultaneous constraint solve.

libslvs authority

Hard housing mounts, shaft axes, gear distances, face overlap, zero placement DOF, and valid SE(3).

success
Assembled contract

Writes model.urdf, model.mjcf, kinematic_model.json, solved world frames, and assembly_constraint_report.json.

Failure classification
  • libslvs inconsistency, residual, axis, DOF, or face-overlap failure raises AssemblerError(kind="authoritative_solver").
  • Structural/name failures use existing contract repair, then Boss routing.

05Solver-failure Analyzer transaction

Generate candidates

Python computes allowed pose/seat candidates and exact rebuild scope.

Read-only Analyzer

Searches artifacts, logs, source, and KB. It must simulate before selecting one candidate ID.

LocalRepairTransaction

Snapshots affected sub state and disk bytes, applies one candidate, then reassembles through libslvs.

Solver accepts

Adopt local_repair_N/ in the same Boss iteration.

Still invalid

Try the next bounded attempt with the new structured solver report.

Exhausted/escalated

Rollback byte-for-byte, then use contract repair or original Boss routing.

Trace
  • analyzer_traces/slvs_<failure_id>_attempt_N.json
  • Analyzer never writes source, invents coordinates, or bypasses the solver.

06Post-assembly gates

Module consistency

Meshing gears must have the same module.

Solved mesh distance

Checks compiler-solved world frames—not Boss guesses.

Auto-nudge

Separates non-seamed overlaps and records a Manager hint; does not silently validate a bad seam.

Assembled support

Weld chain to root blocks on floating subs; orientation-dependent grounding is warning-only.

Blocking interface result: return to Boss before expensive judgment or physics.

07Real-solid precheck + physical housing repair

Structured precheck

Loads the assembled URDF. Checks realized frames, gear distance, unseamed AABBs, and authoritative real-solid intersection at the unchanged 30% threshold.

precheck_report.json

Stable failure/violation IDs; seam, sub, namespaced/local links, shaft role, overlap fraction, threshold, and observations.

Candidate proof

Requires three unique solved shaft lines and six front/rear mappings; transforms intersections into plate-local 2D centers.

Geometry safety

Proves editable CQ constructs, axis/diameter/depth provenance, edge margin, bore web thickness, and complete transaction scope.

Precheck Analyzer

Inspects the mapping, old/new centers, preserved cutter properties, checks, target IDs, and two-link rebuild scope.

Transactional physical patch

Patch front/rear plate scripts to explicit three-point patterns; rebuild only the two plates; synchronize six seat frames to those same centers.

reassemble + rerun precheck
Strict acceptance

All targets disappear; no new violation signature; aggregate overlap decreases; libslvs and affected URDFs remain valid; precheck is fully clean.

Any regression

Rollback every source, frame, mesh, model, and in-memory change byte-for-byte.

Original routing remains

Interface → Boss. Local sub fault → blamed Manager. No threshold suppression or bearing/frame-only substitute.

Attempt artifacts
  • precheck_local_repair_N/candidate_set.json
  • analyzer_decision.json, assembly_constraint_report.json, precheck_report.json, acceptance.json, URDF/MJCF
  • analyzer_traces/precheck_<failure_id>_attempt_N.json

08Judge, physics & keep-best

Six-view appearance judge

Checks assembled completeness, proportions, floating parts, and prompt match. Suggestions feed a Boss replan.

Driven physics

PyBullet or MuJoCo drives the mechanism, checks transmission/stability, and localizes blame to a sub or interface.

Score + monotonic loop

Combines physics, precheck, and judge. Snapshot a new best; restore the prior best after regression.

Stop: pass + score target, plateau, max iteration, safety ceiling, or unavailable physics. Continue: localized blame reruns one Manager; interface blame replans the Boss.
Final outputs
  • views/, judge.json, physics recordings and metrics
  • best_snapshot/, result.json, run.json, complete run.log

09Deliverable

Accepted articulated machine

Assembled URDF + MJCF, per-link CAD/STLs, solved frame report, precheck evidence, appearance verdict, and task-oriented physics evidence.

Disk-backed run history

Every Boss iteration and local repair has its own directory. Prior assemblies remain inspectable; passing subs may enter the local KB memory.

R最终路由：修复失败不会吞掉原始故障

✓ assembly + precheck clean→ six-view judge → physics → score / keep-best。
↩ interface / seam fault→ Boss re-plan；replan_blamed 指定受影响 subs，其他复用。
↩ sub-local fault→ feedback_by_sub；只重跑 blamed Manager。
✓ solver transaction 成功→ 返回 assembly success 主线。
✕ transaction escalation/failure→ byte-for-byte rollback → contract repair / Boss。
✕ structural/name assembler fault→ `_try_contract_repair("assembler")`；仍失败再 Boss。

Text-only workflow

  1. Parse CLI flags and create a disk-backed Boss session.
  2. Boss decomposes the prompt into subassemblies and typed seams.
  3. Deterministic Boss gates reject invalid topology before CAD.
  4. Managers build subassembly connection graphs in parallel.
  5. mate_solver compiles each graph into a local kinematic model.
  6. CAD workers create and validate each physical link.
  7. Subdebugger resolves real-solid local conflicts; frame and compile gates rerun.
  8. Assembler namespaces and merges all accepted subs.
  9. libslvs authoritatively solves all cross-sub placement constraints.
  10. A solver failure may enter a bounded read-only Analyzer transaction.
  11. Post-assembly module, spacing, overlap, and support gates run.
  12. Structured precheck measures real-solid collisions.
  13. A supported housing collision may enter the six-bore physical repair transaction.
  14. Appearance judge reviews six assembled views.
  15. Physics drives the mechanism and localizes failures.
  16. Scoring snapshots improvements and restores regressions.
  17. Pass yields the complete articulated machine and evidence bundle.
