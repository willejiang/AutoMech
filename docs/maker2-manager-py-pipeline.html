manager_py（方案B）相对标准 hierarchy 路径的改动

  • Worker 被吸收 — manager 直接写参数化 CadQuery；evaluate_manager_python 在解析时就构建并导出每个 STL。orchestrator_boss.py:650
  • 坐标全局、来自 params — boss 发一个 params.py（根值函数）；manager 用 place_part(axis=params.<frame>_axis(), xyz=params.<frame>()) 让零件直接落在全局坐标。py_manager.py:102
  • Cross-sub 求解跳过 — assembler 不再跑 libslvs，pose 已是全局。
  • 几何 compiler 跳过 — 强制 legacy，避免生成与 params 冲突的第二套坐标。orchestrator_boss.py:1177
  • 被禁用的 gate — 连通/frame-drift/seam-agreement gate 与 conflict-gate + subdebugger 全部关闭：它们假设 manager_py 不产出的 JSON 连接图/声明式 frame，且移动 pose 会破坏 params 骨牌真值。orchestrator_boss.py:516,737,1284
  • params 成为 precheck 真源 — precheck exec plan.params_text，直接读取 frame 世界坐标。precheck.py:181
